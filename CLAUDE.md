# «Подход» — памятка для Claude

## Как работать (экономия токенов)
- Отвечать по-русски, коротко: результат + что нужно от пользователя. Без пересказа уже сделанного.
- index.html ~700 КБ — НИКОГДА не читать целиком. Только `grep -n` и `sed -n 'N,Mp' | cut -c1-250`.
- Правки — одним Python-патчем с проверкой якорей (`assert s.count(a)==1`), не переписывать готовое.
- После правки: вытащить `<script>` и `node --check`.
- Скриншоты — только при изменении внешнего вида, один сводный снимок.
- Тесты — только по затронутой части; полный набор — перед выпуском.
- Не открывать большие логи: `tail`/`grep`.

## Проект
- Одностраничное офлайн-PWA: `index.html` (весь код), `sw.js` (кеш). Без библиотек и CDN, графика — инлайн-SVG.
- Сайт: GitHub Pages из `main` → https://bahtiyarg308-dot.github.io/podhod/
- Каждый выпуск: `APP_VERSION` в index.html и `VERSION` в sw.js; новый лист «Что нового» через флаг `vNNseen`.
- Коммиты по-русски. Старые данные не ломать, новые поля — необязательные; старое приложение партнёра не должно падать.
- Телефоны 320–432 px, тёмная и светлая темы, поля ввода 16px.
- Не трогать: настоящий gist пользователя, ключи ghp_ из старых переписок; синхронизацию через GitHub только дополнять.

## Устройство кода
- Состояние `S`, `render()` с морфингом DOM, действия `A{}`, ввод `IN{}`, листы `SHEETS{}` + `openSheet()`; хранилище IndexedDB `KV` ('meta', 'p:'+pid, 'remote').
- Модули версий вставлены перед `/* ================= events ================= */`.
- Аккаунты 2.8: Firebase по REST без SDK (`FB`, `CL`, `cloudSync`, `cloudSyncAcc`, `cloudPartners`, `cloudGistMigrate`). Firestore база `default`:
  `users/{uid}/pv/profile` (личное), `users/{uid}/pb/main|chat` (видят партнёры), `users/{uid}/w/{YYYYMM}`, `invites/{code}`, `links/{owner}_{reader}`. Правила — `firestore.rules` (пользователь вставляет вручную в консоли Firebase).
- Партнёры (gist и облако) живут в `S.remote` по sid; облачные помечены `cloud:1`, также в `S.cremote`.

## Проверки
- Playwright уже установлен; сервис-воркер в тестах блокировать (`serviceWorkers:'block'`), данные класть в IndexedDB до reload.
- Настоящий Firebase из Node: `NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt node …`; временные аккаунты после теста удалять.
