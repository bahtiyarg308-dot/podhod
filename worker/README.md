# ИИ-посредник для «Подхода»

Небольшой воркер Cloudflare между приложением и ИИ. Он нужен, потому что приложение открыто всем и ключи в нём хранить нельзя.

- Пошаговая инструкция с кнопкой «Скопировать код»: страница `worker/index.html` (после публикации — `https://bahtiyarg308-dot.github.io/podhod/worker/`).
- Код: `podhod-ai.js` (ES-модуль для Workers). Проверки без интернета: `node worker/test.mjs`.
- Что настроено в панели Cloudflare, то и работает: привязки `LIMITS` (KV) и `AI` (Workers AI), секреты `GROQ_API_KEY`, `GEMINI_API_KEY`.
- Ключи вводятся только в панели Cloudflare. В чат, в репозиторий и в приложение их не вставлять.
