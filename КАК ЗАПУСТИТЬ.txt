«ПОДХОД» — дневник тренировок
=============================

Приложение работает без интернета, без аккаунтов и без Claude.
Все данные хранятся на телефоне. Нужно один раз бесплатно выложить
эту папку в интернет, чтобы открыть её с телефона и установить.

-----------------------------------------------------------------
ШАГ 1. Бесплатно выложить на GitHub Pages (5 минут, с компьютера)
-----------------------------------------------------------------
1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Справа вверху «+» → «New repository».
   Название: podhod. Видимость: Public. Нажмите «Create repository».
3. На открывшейся странице нажмите ссылку «uploading an existing file».
4. Перетащите в окно ВСЁ содержимое этой папки:
   index.html, sw.js, manifest.webmanifest и папки fonts и icons.
   Внизу нажмите «Commit changes».
5. Откройте «Settings» → слева «Pages».
   В «Source» выберите «Deploy from a branch», ветка «main», папка «/ (root)» → «Save».
6. Через 1–2 минуты приложение будет доступно по адресу:
   https://ВАШ-ЛОГИН.github.io/podhod/

-----------------------------------------------------------------
ШАГ 2. Установить на телефон
-----------------------------------------------------------------
Android (Chrome): откройте ссылку → меню ⋮ → «Установить приложение».
iPhone (Safari):  откройте ссылку → «Поделиться» (квадрат со стрелкой)
                  → «На экран “Домой”» → «Добавить».

После установки приложение открывается с иконки и работает офлайн.
Даже если когда-нибудь удалить страницу на GitHub, установленное
приложение продолжит работать.

-----------------------------------------------------------------
ВАЖНО: резервные копии
-----------------------------------------------------------------
У каждого телефона свои данные. Раз в пару недель:
Настройки → Резервная копия → «Сохранить / отправить»
и отправьте файл себе в Telegram «Избранное» или в Google Диск.
При смене телефона: установите приложение и нажмите
«Восстановить из файла».

Перенос программ из версии в Claude: там в Настройках нажмите
«Экспорт JSON», а здесь — «Восстановить из файла».

-----------------------------------------------------------------
Обновление приложения в будущем
-----------------------------------------------------------------
Замените файлы в репозитории новыми и поменяйте номер версии
в первой строке sw.js (например, podhod-1.0.1). Телефон сам
предложит «Обновить», данные при этом сохраняются.
